## 🚀 About The Project

**Mini-Virus-in-Python** is an experimental systems engineering project designed to explore low-level operating system automation, file manipulation, and process triggers using pure Python standard libraries. It handles text payload injection, media playback orchestration, and system-level control functions (such as automated shutdown commands).
